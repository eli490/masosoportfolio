How I work

One path from requirement to release

I stay with a feature through every stage, including production support after it ships.

  1. STAGE 1RequirementsReview for clarity and testability. Agree acceptance criteria with developers and product owners.
  2. STAGE 2Test designPlan, estimate and write test cases. Rank what to test by risk.
  3. STAGE 3AutomationPython, Selenium, Playwright and Appium suites, plus API checks in Postman and REST Assured.
  4. STAGE 4PipelineJenkins, Docker and Kubernetes run the suites so builds are verified on every merge.
  5. STAGE 5Sign-offFinal QA approval based on results, open defect risk and release readiness.
